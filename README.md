# JAI 2026 · Catálogo químico interativo PLE 3

Catálogo com os 71 sinais cromatográficos atribuídos ao extrato de *Melaleuca alternifolia* (PLE 3), com busca, fichas e consulta dinâmica de propriedades e estruturas no PubChem.

## Publicar com GitHub Pages

1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Source: Deploy from a branch**.
3. Configure **Branch: main** e **Folder: /docs** e clique em **Save**.
4. Depois que o GitHub indicar **Your site is live**, abra https://gustaugalde.github.io/jai2026-ple3/ e teste as fichas.

O catálogo está em [docs/index.html](docs/index.html). A relação dos 71 picos está em [CSV](docs/lista-71-compostos.csv).

**Nota científica:** nomes baseados nas atribuições do cromatograma, sem implicar confirmação por padrão analítico. Propriedades e imagens moleculares são consultadas sob demanda no PubChem; resultados ambíguos requerem avaliação crítica.
